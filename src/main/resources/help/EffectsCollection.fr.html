Collections

À quoi servent les collections ?

Une collection est enregistrée dans une base de données afin de garder vos paramètres pour une utilisation ultérieure dans un script. Afin d'enregistrer ces données dans votre script, veuillez lire les instructions ci-dessous.

Comment ajouter une collection ?

Pour ajouter une collection, il suffit de la nommer (à côté de la liste déroulante) et de presser le bouton 'Ajouter'. Vous avez créé une collection qui pour l'instant est vide.

Comment peupler une collection ?

Pour ajouter des effets à une collection, vous devez créer un nouvel effet par le menu contextuel (bouton droit de la souris et sélection sur la zone voulue) de l'une des deux zones, puis si vous avez opté pour la zone gauche, vous devez envoyer l'effet dans la zone droite afin de l'éditer. Toujours avec le menu contextuel.

Comment éditer un effet ?

Pour éditer un effet, il suffit de le sélectionner dans la zone du script de l'onglet numéro 1 puis de choisir l'onglet numéro 2, afin de l'envoyer dans l'outil d'édition.
